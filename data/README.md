# Data files

Place the following files in this directory before running the notebooks:

| Project | Expected file |
|---|---|
| Olympic visualization | `athlete_events.csv` |
| Facebook stock visualization | `fb_stock_prices_2018.csv` |
| Renewable energy production | `share-of-electricity-production-from-renewable-sources.csv` |
| Renewable energy consumption | `renewable-energy-consumption-by-country.csv` |
| Diabetes cleaning | `diabetes.csv` |

## Public source notes

- Olympic athlete data: Randi H. Griffin, *120 years of Olympic history: athletes and results* on Kaggle.
  https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results
- Renewable electricity production: Our World in Data.
  https://ourworldindata.org/grapher/share-of-electricity-production-from-renewable-sources

The other source files are not redistributed here. Keep the original data files you used and rename/copy them to the filenames above.
